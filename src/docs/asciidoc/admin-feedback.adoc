=== 어드민 피드백 목록 조회

* 어드민 "버그제보" 메뉴의 목록입니다. `Authorization: Bearer {accessToken}` (어드민 토큰) 이 필요합니다.
* `snapshot` 은 목록에서 반환하지 않습니다. (상세에서만 포함)
* `severity`/`status` 는 어드민 트리아지 값이며, 트리아지 전에는 기본값(`low`/`open`)으로 노출됩니다.

=== 어드민 피드백 상세 조회

* 단건 상세입니다. 제출 시점 컨텍스트인 `snapshot` 을 포함합니다. (`snapshot` 내부 키는 camelCase, 미수집 시 `null`)
* 존재하지 않는 ID 는 `404` 를 반환합니다.

=== 어드민 피드백 트리아지

* 심각도(`severity`)·상태(`status`)를 변경합니다. 둘 중 하나 또는 둘 다 보낼 수 있습니다(부분 수정).
* 값은 소문자 문자열입니다. 잘못된 값/빈 본문은 `400` 을 반환합니다.
* 트리아지 레코드가 없으면 기본값으로 생성한 뒤 변경값을 적용합니다. 응답은 수정된 row(`snapshot` 미포함)이며 `updated_at` 이 갱신됩니다.
